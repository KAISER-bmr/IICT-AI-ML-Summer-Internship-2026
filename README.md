# 📌 About this Repository

This repository contains the projects completed during the **Summer Internship in Artificial Intelligence & Machine Learning 2026** conducted by the **Indian Institute of Computing and Technology (IICT)**.

The objective of this internship was to apply Machine Learning, Natural Language Processing (NLP), and Deep Learning techniques to solve real-world cybersecurity and misinformation detection problems.

The repository currently contains two complete end-to-end machine learning projects:

- 📰 Fake News Detection using Text Classification
- 🛡️ Phishing Email Detection using NLP and Machine Learning

Each project includes:

- Source Code
- Technical Report
- Presentation Slides
- Workflow Diagrams
- Experimental Results

# 📁 Projects

## Project 1 — AI-Powered Fake News Detection

### Objective

Develop a machine learning pipeline capable of classifying news articles as **REAL** or **FAKE** using Natural Language Processing and supervised learning algorithms.

### Highlights

- Text preprocessing
- TF-IDF Vectorization
- KNN
- Logistic Regression
- Random Forest
- Neural Network (MLP)
- Model comparison
- Cross Validation

---

## Project 2 — AI-Driven Phishing Email Detection

### Objective

Design an intelligent phishing email detection system using Natural Language Processing and Machine Learning capable of identifying malicious emails before they reach users.

### Highlights

- Email preprocessing
- TF-IDF Features
- Metadata Feature Engineering
- Logistic Regression
- Random Forest
- Naive Bayes
- Neural Network (MLP)
- Performance Evaluation

# 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/<your-username>/IICT-AI-ML-Summer-Internship-2026.git
```

Navigate to any project

```bash
cd Project1_FakeNewsDetection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python fake_news_detection.py
```
