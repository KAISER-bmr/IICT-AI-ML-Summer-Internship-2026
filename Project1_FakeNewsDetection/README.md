## 📌 Project Overview

This project aims to build a machine learning model capable of classifying news articles as **REAL** or **FAKE** using **Natural Language Processing (NLP)** and supervised machine learning techniques.

The project is being developed as part of the **Summer Internship in AI & ML 2026** conducted by the **Indian Institute of Computing and Technology (IICT)**.
